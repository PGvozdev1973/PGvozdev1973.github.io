## Regenerating reading editions

Run `python3 scripts/build-reading-pages.py` after an approved source update. It uses only Python's standard library and preserves manuscript wording and source files. Review the edition metadata and sitemap date in the generator when publishing a new edition. The section-boundary assertion intentionally requires review if the chapter structure changes.

The reading index includes GitHub and Zenodo alternatives. HTML, text downloads and smaller sections improve format compatibility, but cannot guarantee access through a provider's restricted browsing tool or search-engine indexing.
